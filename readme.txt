beatoraja用スキン　Luxe Flat (beta) ver 1.3.0a

last updated: 2024/09/22
released: 2023/02/15


本スキンはbeatoraja用のフルHD(1920x1080)スキンです。選曲スキン・決定スキン・リザルトスキンを同梱しています。
使用する際は展開して出てきたLuxe_Flatフォルダをskinフォルダ内に配置してください。


■動作環境

・対応本体
　 beatoraja 0.8.7  推奨

・解像度
　FULLHD(1920×1080) 、FULLSCREEN  推奨
　
　上記以外の環境では正しく動作しない
　可能性があります。


■カスタマイズ機能

・Luxe_Flat/customizeフォルダ内から以下カスタマイズを導入できます。

　・選曲スキンの背景画像 / 動画（backgroundフォルダ）
　・決定スキンの背景画像（decide_bgフォルダ）
　・マスコットキャラ画像（mascotフォルダ）
　・NO IMAGE時に表示する画像（no_stagefile_imageフォルダ）
　・リザルトスキンの背景画像（resultbgフォルダ）
　・シャッター演出時の背景画像（shutterフォルダ）
　・選曲スキンの効果音（soundフォルダ）

・BGM素材・sound素材をLuxe_Flatフォルダ内の
　bgmフォルダ・soundフォルダに同梱しています。


以下の制限に従う限り、本スキンを使用、改変および再配布することを許可します。

・本スキンの全部または一部を金銭的対価を得る目的で改変、配布する行為の禁止。
・不正な手段を用いて生成されたBMS(派生フォーマット含む)を再生することの禁止。
・不正な手段を用いて生成された画像等のデータを使用した本スキンの改変、および使用の禁止。

フォントの扱いについては同梱しているライセンスをご覧ください

2024/09/22 EGRET.
